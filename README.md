# pg4_gr7
This repository is for managing group work in our semester project.


Get started:\
    Using conda
    https://www.anaconda.com/download

    Go to config directory:

    conda env create -f env.yaml
    conda activate gr7-ml

Dataset download:\ 
    https://sid.erda.dk/public/archives/daaeac0d7ce1152aea9b61d9f1e19370/published-archive.html

    Download the training data: GTSRB_Final_Training_Images.zip\
    Download the test data: GTSRB_Final_Test_Images.zip\
    
    Unzip each of the data and put them into the data/GTSRB/Final_(Training/Test) folder
